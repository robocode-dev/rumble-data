# G-001 — Bot authors and contributors want a trustworthy, auditable ranked leaderboard

Battle contributors run ranked battles and bot authors want to see how their bots compare, but neither will trust a leaderboard that anyone could quietly edit. `README.md` states the dashboard "ranks each game type by APS" and shows "how many battles and distinct matchups contribute to each entry" specifically so a reader can judge how much to trust a given ranking. `CONTRIBUTING.md` and `GOVERNANCE.md` back this with immutable, content-addressed raw facts and a documented CI-only writer boundary.
