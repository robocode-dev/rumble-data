# G-003 — The project wants to keep running from public information alone, without private dependencies

`GOVERNANCE.md`'s "Fork drill" requires forking the repository once each quarter, enabling its workflows and Pages, running aggregation locally, and recording the result — explicitly "to show that public source and documentation are enough to recover result ingestion and the dashboard without personal credentials or external services." This is a standing organizational want (continuity and community trust independent of any one maintainer or account), not a one-off task.
